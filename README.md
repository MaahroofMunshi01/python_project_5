# Employee Management System

## 📌 Project Overview
The Employee Management System is a menu-driven Python application developed using Object-Oriented Programming (OOP) concepts. It allows users to create and manage different types of people and employees, including Employees, Managers, and Developers.

The project demonstrates inheritance, encapsulation, polymorphism, and class relationships while providing basic employee management operations.

## 🚀 Features

- **Create Person:** Add a person with name and age.
- **Create Employee:** Add an employee with employee ID and salary.
- **Create Manager:** Create a manager with department details.
- **Create Developer:** Create a developer with a primary programming language.
- **Display Details:** View details of all people or employees.
- **Update Salary:** Update an employee's salary using their employee ID.
- **Remove Employee:** Remove an employee from the system using their ID.
- **Input Validation:** Handle invalid integer and float inputs.
- **Salary Validation:** Prevent negative salary values.
